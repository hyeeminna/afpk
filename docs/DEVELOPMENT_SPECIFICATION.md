## 1. 프로젝트 개요 및 기술 스택

### 1.1 서비스 정의
* **서비스명:** 재무주치의 (은퇴 안심 케어 / AFPK 공인 은퇴설계 AI)
* **핵심 타깃:** 은퇴를 앞두거나 은퇴를 시작한 50~60대 대한민국 직장인 및 자영업자 (전 연령 확장 가능)
* **핵심 가치:** 
  1. 로그인 없이도 3분 만에 시작하는 간편 자가진단
  2. AFPK 표준 규격의 정밀 재무상태표 및 은퇴 전후 월간 현금흐름 비교 분석
  3. 4대 재무목표 타임라인 및 직관적인 신호등 카드 진단 (🟢 달성 가능 / 🔴 위험 경보 / 🟡 사전 합의 필요)
  4. Google Gemini 2.5 Flash 기반의 지능형 실시간 AI 재무상담
  5. 한OO 세무사 카카오톡 1:1 상담 QR 연동
  6. 신규 고객 직접 입력을 위한 '공란 양식 모드'와 모범안 복원을 위한 'Supabase 데이터 불러오기' 지원

### 1.2 기술 스택 (Tech Stack)
* **Frontend Framework:** Next.js 16.0.3 (App Router 방식)
* **UI Library:** React 19.2.0, TypeScript 5.x
* **Styling:** Tailwind CSS 4.x, Lucide React, Google Material Symbols Outlined
* **Theme Management:** `next-themes` (다크 모드 / 라이트 모드 완벽 대응)
* **Backend & Database:** Supabase Cloud (PostgreSQL 17), PostgREST, Row Level Security (RLS)
* **Authentication:** Supabase Auth (Google OAuth 2.0 연동)
* **AI Engine:** Google Gemini Interactions API (`@google/genai`, 모델: `gemini-2.5-flash`)
* **Image Processing:** Sharp 0.35.5 (4K 고해상도 디자인 캡처 및 화면 합성)
* **Version Control:** Git (`https://github.com/hyeeminna/afpk.git`, main 브랜치)

## 3. 화면별 상세 기능 및 UI/UX 구현 명세

### 3.1 홈 화면 (`/`)
* **Hero 섹션:**
  * 표제: "은퇴 후 30년, 내 돈은 과연 안전할까요?"
  * 닥터 캐릭터 일러스트 배너 탑재
  * CTA: `3분 무료 점검 시작하기 →` (클릭 시 `/diagnosis`로 스무스 이동)
* **4대 핵심 고민 선택 카드 (단일 선택):**
  1. 은퇴 후 월 생활비 300만 원 마련 (생활비)
  2. 국민연금·퇴직연금 수령 시기 및 절세 (연금)
  3. 은퇴 전 대출(담보대출) 전액 상환 (대출)
  4. 모아둔 자산 안정적 굴리기 (자산)
  * 선택된 고민은 `sessionStorage`에 보존되어 `/diagnosis` 진입 시 상단에 '재무주치의 맞춤 안내 배너'로 자동 연동됨.
* **월 소득 입력 바:**
  * 슬라이더 및 직접 입력 지원 (기본 300만 원 ~ 800만 원 이상)
* **서비스 특징 및 FAQ:** 카드형 UI로 직관적인 설명 제공.

### 3.2 STEP 01 재무설계안 등록 (`/diagnosis` Step 1)
* **계산기형 숫자 입력 포맷팅:**
  * 한글, 영문, 특수문자 입력을 원천 차단하는 `formatCalculatorNumber` 함수 적용.
  * 숫자를 입력할 때마다 즉시 3자리 콤마(`,000` 구조) 적용.
* **입력 필드:**
  * `자산 현황`: 총 자산 (예: `1,721,710,000` 원)
  * `부채 현황`: 총 부채 (예: `250,000,000` 원)
  * `월 소득 및 지출`: 세후 월 소득 (`8,050,000` 원) / 월 지출 (`7,330,000` 원)
  * `비상자금 설정`: 목표 비상자금 (`22,000,000` 원, 월 지출의 약 3.0개월분 자동 계산)
  * `재무 목표 설정`: 목표 이름, 목표 금액, 목표 시점
* **우측 실시간 계산 요약 패널:**
  * 사용자가 좌측 입력을 변경하는 즉시 **순자산(총자산 - 총부채)**, **월 잉여금(소득 - 지출)**, **저축률(%)**이 0.1초 만에 재계산되어 동기화됨.

---

### 3.3 STEP 02 월별 변동 입력 (`/diagnosis` Step 2)
* **2026년 9월 vs 10월 독립 데이터 레코드:**
  * 상단 토글(`< [ 2026년 9월 ] [ 2026년 10월 ] >`)을 통해 월 전환.
  * 9월과 10월 각각의 수치(수입, 고정지출, 변동지출, 투자/저축, 자산/부채변동)가 독립 상태로 저장되어 0원으로 초기화되지 않음.
* **저장 버튼:**
  * 기존 `분석하기` 문구를 삭제하고 **`[ 💾 2026년 9월 저장하기 ]`**, **`[ 💾 2026년 10월 저장하기 ]`**로 명확히 변경.
* **불필요 카드 제거 및 순자산 추이 차트:**
  * Supabase 데이터와 맞지 않던 '달성률(78%)', '저축률(12.9%)' 카드를 영구 삭제.
  * 순자산 추이 SVG 라인/그라디언트 차트 제공.
  * 하단에 Supabase 기반 **월별 재무 변동 비교 테이블 (MoM 증감률 및 변동 사유)** 탑재.

### 3.4 STEP 03 Gemini AI 재무상담 (`/diagnosis` Step 3)
* **실시간 AI 상담:** Google Gemini 2.5 Flash 연동 (`/api/chat` 엔드포인트).
* **3대 원터치 추천 질문 칩:**

### 5.2 Supabase SQL 보안 및 RLS 필수 규칙 (`AGENTS.md`)
새로운 로컬 환경에서 테이블을 구성하거나 마이그레이션할 때 반드시 다음 규칙을 엄격히 준수해야 합니다:
```sql
-- 1. RLS 활성화 필수
ALTER TABLE public.<table_name> ENABLE ROW LEVEL SECURITY;

-- 2. 명시적 권한 부여 (GRANT) 필수
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE public.<table_name> TO authenticated;
GRANT SELECT ON TABLE public.<table_name> TO anon;

-- 3. 인증된 사용자 본인 데이터 보안 정책 (Policy)
CREATE POLICY "Allow authenticated users to select own data"
  ON public.<table_name> FOR SELECT TO authenticated
  USING (auth.uid() = user_id);

CREATE POLICY "Allow authenticated users to insert own data"
  ON public.<table_name> FOR INSERT TO authenticated
  WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Allow authenticated users to update own data"
  ON public.<table_name> FOR UPDATE TO authenticated
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
```
